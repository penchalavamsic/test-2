## Floating License Configurations — Bulk Actions (Batch FLC-D)

### Selection Toolbar, Select Loaded & Clear, Dates Panel, Capacity Panel, Delete Action, Safe Restoration (FLC-D: SUD-1889 to SUD-1916, 28 tests)

**Verified Floating License Configurations selection toolbar bulk-action behavior:**

- **Selection Toolbar Structure (7 tests):** Dynamic selected count "N selected" (LIMAS-SUD-1889), Select Loaded button accessible name and keyboard focus (LIMAS-SUD-1890), Clear button accessible name and focus (LIMAS-SUD-1891), Dates button accessible name and focus (LIMAS-SUD-1892), Capacity button accessible name and focus (LIMAS-SUD-1893), Delete button accessible name and focus (LIMAS-SUD-1894), toolbar hidden when no cards selected (LIMAS-SUD-1895).
- **Select Loaded and Clear (5 tests):** Select loaded selects all visible configurations (LIMAS-SUD-1896), selected count updates dynamically after select all (LIMAS-SUD-1897), Clear removes all selections and hides toolbar (LIMAS-SUD-1898), Select loaded scopes to search-filtered cards only (LIMAS-SUD-1899), Clear after Select loaded restores no-selection state (LIMAS-SUD-1900).
- **Dates Panel (7 tests):** Dates button opens an **inline panel** (not a dialog) with "Update Dates" heading (LIMAS-SUD-1901), Expiration Date and Maintenance Date textboxes present (LIMAS-SUD-1902), current default values from runtime cards displayed (LIMAS-SUD-1903), "Use expiration date for maintenance" checkbox with role="checkbox" (LIMAS-SUD-1904), Cancel and Update Dates controls present (LIMAS-SUD-1905), Cancel closes panel and leaves selections unchanged (LIMAS-SUD-1906), reopening after Cancel shows form with original default values (LIMAS-SUD-1907). **No date changes submitted.**
- **Capacity Panel (6 tests):** Capacity button opens an **inline panel** with "Update Capacity" heading (LIMAS-SUD-1908), Number of Licenses and Maximum Checkout Time inputs present (LIMAS-SUD-1909), both inputs have role="spinbutton" for numeric-only entry (LIMAS-SUD-1910), Cancel and Update Capacity controls present (LIMAS-SUD-1911), Cancel closes panel and leaves selections unchanged (LIMAS-SUD-1912), reopening after Cancel shows form with original default values (LIMAS-SUD-1913). **No capacity changes submitted.**
- **Delete Action (2 tests):** **Delete is immediately destructive — no confirmation dialog appears.** The button transitions to "Deleting…" with disabled state during execution (LIMAS-SUD-1914). Confirmed via live UI observation that no dialog, modal, or confirmation step is presented (LIMAS-SUD-1915). Delete is never clicked in tests; behavior is documented from stable UI evidence.
- **Safe Restoration (1 test):** Full restore to clean state — no selections, no open panels, heading and user group summary visible (LIMAS-SUD-1916).

**Key design decisions:**
- Selection toolbar appears with 5 buttons: Select loaded, Clear, Dates, Capacity, Delete — plus dynamic count text "N selected".
- Dates and Capacity panels are **inline panels**, not dialogs — they appear below the toolbar in the main content area.
- The "Update Dates" and "Update Capacity" buttons are disabled until the user modifies a value — preventing accidental no-op submissions.
- Delete is confirmed to be **immediate with no confirmation step** — the button text changes to "Deleting…" and becomes disabled during execution.
- All panel Cancel buttons restore to the pre-open state and leave selections intact.
- Panel reopen after Cancel restores original default values (no stale form state).
- Select loaded respects the current search/filter scope — only visible loaded cards are selected.

**Blocked cases: 0.** Select-loaded and multi-select coverage is data-dependent when fewer than 2 cards exist.
