# LIMAS-SUD-1903: Explicit bulk date values

## Prerequisites
Authenticated account with tab access and the relevant runtime record. Skip only when required data is absent.

## Actions
Open Dates for a selected configuration. Verify both fields start blank and Update Dates is disabled. Fill a future expiration date, verify Update Dates enables, then Cancel.

## Expected result
No existing date is silently applied; a new value is required. No mutation is submitted.
