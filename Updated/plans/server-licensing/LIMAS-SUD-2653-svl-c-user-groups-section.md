# LIMAS-SUD-2653: User Groups section is visible with heading and Add Group button

**Batch:** SVL-C (Edit Customer Dialog)
**Profile:** SUPER_USER_ADMIN_USER
**Evidence Source:** Live UI observation

## Atomic Behavior
The User Groups section is visible inside the Edit Customer dialog, containing a heading and an "Add Group" button.

## Preconditions
- Edit Customer dialog is open on a customer card with existing user groups (e.g., AATestCustomer with group: testGroup)

## Steps
1. Open the Edit Customer dialog
2. Scroll to the User Groups section
3. Verify the section heading is present
4. Verify the "Add Group" button is visible

## Expected
- User Groups section is visible
- Section has a heading (e.g., "User Groups")
- "Add Group" button is visible and enabled

## Observed
- User Groups section visible with heading
- "Add Group" button present and clickable
